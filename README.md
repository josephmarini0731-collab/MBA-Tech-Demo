# System Test Plan – MBA Tech Demo

## Purpose
This repository was created for Professor Jones’ MBA Systems assignment. It demonstrates how to document and manage a basic software quality assurance process using GitHub for version control and issue tracking.

## Contents
- **System_Test_Plan.docx** – The complete test plan document with objectives, scope, environment, test cases, and results.  
- **GitHub Issues** – Contains labeled issues that simulate defect tracking and feature testing.  
- **README.md** – Overview and navigation guide for the repository.

## Instructions
1. Open **System_Test_Plan.docx** to review the full test documentation.  
2. Browse the **Issues** tab to see each test case and related outcome.  
3. This project simulates a system test for a web chatbot that helps customers with orders, returns, and product questions.
